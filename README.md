# Hunch

A mindful daily thoughts & media stream application built with React Native (Expo SDK 58), Node.js Express, Neon PostgreSQL, and Cloudflare R2 storage.

## Project Structure

- `app/`: React Native Expo mobile application.
- `server/`: Node.js Express REST API backend with PostgreSQL database and Cloudflare R2 media upload services.

## Tech Stack

- **Mobile Client**: Expo SDK 58, React Native 0.88, React 19, `expo-audio`, `expo-video`, `expo-camera`, `expo-blur`.
- **Backend**: Node.js, Express, Neon PostgreSQL, AWS S3 SDK for Cloudflare R2 presigned streaming.
